# ⚡ Cyberpunk HUD Portfolio

Welcome to the source code for my personal portfolio, built with React and Vite. The UI is designed with a high-tech, futuristic Cyberpunk/HUD aesthetic featuring dynamic grid layouts, glowing terminal text, and custom CSS micro-animations.

## 🚀 Features
- **Immersive HUD Design:** Sci-fi aesthetics utilizing neon glows, bracketed components, and starfield backgrounds.
- **Agentic AI & ML Focused:** Detailed sections highlighting projects in Multi-Agent Systems, LLM Evaluation, and NLP.
- **Interactive Project Showcase:** Expandable project cards with integrated carousels and GitHub/Live links.
- **Responsive Layout:** Fully optimized for both desktop and mobile terminals.

## 🛠️ Tech Stack
- **Frontend:** React (JavaScript/JSX), Vite
- **Styling:** Custom Vanilla CSS (Flexbox/Grid, CSS Variables, Keyframe Animations)
- **Icons:** React Icons & Custom SVGs

## ⚙️ Running Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/Vraj-Priyadarshi/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```
